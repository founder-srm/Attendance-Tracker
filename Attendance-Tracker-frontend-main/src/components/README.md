# Components — Directory Guide

```
components/
├── ui/                    # Primitive UI atoms generated by shadcn/ui
│   └── button.tsx, input.tsx, ...
│
├── admin/                 # Components used exclusively by admin routes
│   ├── AdminDashboard.tsx          — Top-level admin stats/overview widget
│   ├── ManualAttendancePanel.tsx   — Supabase-backed manual attendance tool
│   ├── MeetingManagement.tsx       — Meeting CRUD, QR generation
│   └── MemberManagement.tsx        — Member roster CRUD
│
├── shared/                # Components shared across admin + member views
│   └── RoleBadge.tsx               — Colored pill showing member role
│
└── AuthProvider.tsx        # App-wide session context (wraps Supabase auth)
```

## Adding a new component

- If it is used only on admin pages → put it in `admin/`
- If it is used on both member dashboard and admin pages → put it in `shared/`
- If it is a low-level UI primitive → add it via `npx shadcn@latest add <name>` which targets `ui/`
